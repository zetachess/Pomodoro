# Pomodoro Timer

Una aplicación de escritorio y móvil para organizar tareas, trabajar en sesiones Pomodoro y compartir el progreso diario.

## Funciones

- Temporizador Focus con descansos cortos y largos configurables.
- Lista de tareas independiente, con opción de vincular una al temporizador.
- Historial, estadísticas semanales y logros guardados localmente.
- Resumen diario para compartir por WhatsApp o copiar.
- Interfaz en español, adaptable a móvil y escritorio.

## Desarrollo local

```bash
npm install
npm run dev
```

## Comprobaciones

```bash
npm run lint
npm run build
```

Los datos se guardan en el almacenamiento local del navegador. No se necesita una cuenta ni un servidor de datos.
